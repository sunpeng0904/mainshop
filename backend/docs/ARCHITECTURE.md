```
│  │ Controller  │  Service    │   Mapper    │   Entity    │  │
│  │   控制器     │   服务层    │   数据层    │   实体类    │  │

              ┌───────────────┼───────────────┐

        └──────────┘   └──────────┘   └──────────┘
```

## 模块设计

### 用户模块

```
UserController ──> UserService ──> UserMapper ──> User
                       │
                       ├── 注册、登录
                       ├── 个人信息管理
                       └── 密码管理
```

**权限控制**：
- 普通用户：管理自己的信息
- 管理员：管理所有用户

### 商品模块

```
ProductController ──> ProductService ──> ProductMapper ──> Product
         │                    │
         │                    └── CategoryService
         │
         └── AdminProductController (管理端)
```

**功能**：
- 商品CRUD
- 分类管理（树形结构）
- 国际化支持

### 订单模块

```
OrderController ──> OrderService ──> OrderMapper ──> Order
       │                  │
       │                  ├── OrderItemService
       │                  └── PaymentService
       │
       └── AdminOrderController (管理端)
```

**订单状态流转**：

```
待付款(0) ──支付──> 待发货(1) ──发货──> 待收货(2) ──确认──> 已完成(3)
    │
    └──取消──> 已取消(4)
```

### 支付模块

```
PaymentController ──> PaymentService ──> PaymentMapper ──> Payment
                              │
                              └── WechatPayService
```

**支付流程**：
1. 用户创建订单
2. 调用支付接口生成支付二维码
3. 用户扫码支付
4. 微信回调通知
5. 更新订单状态

### 抽奖模块

```
LotteryController ──> LotteryService ──> LotteryPrizeMapper ──> LotteryPrize
        │                     │
        │                     └── LotteryRecordMapper
        │
        └── AdminLotteryController (管理端)
```

**并发控制**：
- 乐观锁（version字段）防止库存超卖
- 重试机制（最多3次）
- 失败降级处理

## 安全设计

### 认证流程

```
┌────────┐     ┌────────────┐     ┌──────────────┐
│  用户   │────>│ /user/login │────>│ 验证用户名密码 │
└────────┘     └────────────┘     └──────────────┘
                                         │
                                         ▼
                                  ┌──────────────┐
                                  │  生成JWT Token │
                                  └──────────────┘
                                         │
                                         ▼
┌────────┐     ┌────────────┐     ┌──────────────┐
│  用户   │<────│ 返回Token   │<────│ 返回给客户端   │
└────────┘     └────────────┘     └──────────────┘
```

### 权限控制

```java
// 角色定义
ROLE_ADMIN  // 管理员
ROLE_USER   // 普通用户

// 接口权限
/user/**    -> 已认证用户
/admin/**   -> ROLE_ADMIN
/lottery/** -> 已认证用户
```

### 密码安全

- BCrypt 加密存储
- 密码强度校验
- 登录失败次数限制（可扩展）

## 数据库设计原则

### 通用字段

所有表包含以下通用字段：

```sql
create_time DATETIME DEFAULT CURRENT_TIMESTAMP  -- 创建时间
update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP  -- 更新时间
deleted INT DEFAULT 0  -- 逻辑删除（0正常 1删除）
```

### 索引设计

| 类型 | 说明 |
|------|------|
| 主键索引 | 所有表都有自增主键 |
| 唯一索引 | 用户名、订单号等唯一字段 |
| 普通索引 | 外键、状态字段、时间字段 |
| 联合索引 | 高频查询组合 |

### 逻辑删除

使用 MyBatis-Plus 的 `@TableLogic` 注解实现逻辑删除，删除操作自动转换为 UPDATE。

## 缓存策略

### Redis 缓存（可选）

| Key | 说明 | 过期时间 |
|-----|------|----------|
| `user:token:{userId}` | 用户Token | 24小时 |
| `lottery:times:{userId}:{date}` | 抽奖次数 | 当天有效 |
| `product:detail:{id}` | 商品详情 | 1小时 |
| `region:*` | 区域数据 | 永久 |

### 本地缓存

- 抽奖次数：`ConcurrentHashMap`（生产环境建议用Redis）
- 图片缓存：本地文件系统
