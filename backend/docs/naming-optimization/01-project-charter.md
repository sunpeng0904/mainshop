## 2. 项目背景
online-mall 前端项目（Vue 3 + Element Plus）在快速发展中，命名规范不统一，影响代码可读性和维护效率。需要对关键模块进行命名规范化改造。

## 3. 项目目标

### 3.1 业务目标
- 提升代码可读性和可维护性
- 降低新开发者上手成本

### 3.2 技术目标
- 统一采用 Vue 官方推荐命名风格
- 先改关键模块（store、api、components），验证后推广
- 配置 ESLint 命名规则，确保新代码遵循规范

## 4. 项目范围

### 4.1 范围包含
- 组件命名：PascalCase（如 `ProductCard.vue`）
- 变量/函数：camelCase
- 常量：UPPER_SNAKE_CASE
- 文件名：kebab-case
- ESLint 命名规则配置

### 4.2 范围不包含
- Vuex→Pinia 迁移
- TypeScript 改造
- 全量代码改造（本次仅试水关键模块）
