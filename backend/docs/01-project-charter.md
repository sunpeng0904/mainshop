## 2. 项目背景
基于 Spring Boot 构建在线商城后端服务，提供完整的电商功能，包括用户管理、商品管理、购物车、订单、支付、抽奖活动、分享功能等。系统采用前后端分离架构，支持多终端访问。

## 3. 项目目标

### 3.1 业务目标
- 提供完整的电商后端服务
- 支持用户注册、登录、商品浏览、下单、支付等核心业务流程
- 支持分享、圈子、互动等社交电商功能
- 支持抽奖等营销活动

### 3.2 技术目标
- 采用 Spring Boot 2.7 框架
- 使用 MyBatis-Plus 作为 ORM 框架
- 实现 JWT 认证授权
- 支持国际化（i18n）
- 实现乐观锁并发控制

## 4. 项目范围

### 4.1 范围包含
- 地址管理模块优化（省市区三级联动）
- 地址管理模块性能优化
- 地址管理模块用户体验改进

### 4.2 范围不包含
- 其他模块的功能开发
- 前端应用开发
- 生产环境部署运维
