## 改造清单

### 1. API 层改动
**文件**：`src/api/address.js`

新增 3 个方法：
- `getProvinces()` - 获取省份列表
- `getCities(provinceCode)` - 获取城市列表
- `getDistricts(cityCode)` - 获取区县列表

### 2. 前端页面改动
**文件**：`src/views/user/center.vue`

| 改动点 | 改动前 | 改动后 |
|--------|--------|--------|
| 省市区输入 | 3个 el-input 文本框 | 3个 el-select 下拉框 |
| 手机号输入 | 普通输入 | 自动格式化（138 1234 5678） |
| 编辑回显 | 直接赋值 | 异步加载城市/区县后回显 |
| 提交数据 | 前端字段名 | 转换为后端字段名 |

### 3. 新增功能
- 省份选择后自动加载城市列表
- 城市选择后自动加载区县列表
- 手机号输入自动格式化（3-4-4 分隔）
- 编辑时自动加载对应城市/区县数据
- 页面加载时预获取省份数据

### 4. 字段映射
```javascript
// 前端 → 后端（提交时）
{
  receiverName → rcvrName,
  receiverPhone → rcvrTel (去除空格),
  provinceCode → prvcCde,
  cityCode → cityCde,
  districtCode → dstrctCde,
  detailAddress → dtlAddr,
  isDefault → dftIndc (Y/N)
}
```
