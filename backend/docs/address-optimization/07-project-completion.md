## 核心功能

1. **省市区三级联动**：使用 Element Plus el-select 实现，选择省份自动加载城市，选择城市自动加载区县
2. **手机号格式化**：输入时自动以 3-4-4 格式显示（如 138 1234 5678）
3. **编辑回显**：异步加载城市/区县数据后正确回显已选值
4. **字段映射**：前端 camelCase 与后端缩写字段自动转换
