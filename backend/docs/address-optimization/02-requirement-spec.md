# 需求规格说明书 (SRS) — 收货地址优化

## 1. 引言

### 1.1 目的
优化收货地址表单，提升用户填写体验。

### 1.2 范围
前端 `user/center.vue` 中的地址表单功能。

### 1.3 术语定义
| 术语 | 说明 |
|------|------|
| 三级联动 | 省→市→区逐级选择，上级决定下级选项 |
| 手机号回显 | 输入时自动格式化显示（如 138 1234 5678） |

## 2. 功能需求

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-001 | 省市区改为三级联动下拉选择 | P0 |
| FR-002 | 选择省份后自动加载该省城市列表 | P0 |
| FR-003 | 选择城市后自动加载该市区县列表 | P0 |
| FR-004 | 编辑地址时回显已选的省市区 | P0 |
| FR-005 | 手机号输入时自动格式化显示 | P1 |
| FR-006 | 手机号最大长度限制为11位 | P1 |

## 3. 非功能需求

| 编号 | 需求 | 验收标准 |
|------|------|----------|
| NFR-001 | 省市数据加载响应时间 | < 1秒 |
| NFR-002 | 页面功能正常 | 地址增删改查正常 |
| NFR-003 | 构建成功 | npm run build 通过 |

## 4. 数据接口

### 4.1 已有接口
| 接口 | 方法 | 说明 |
|------|------|------|
| /region/provinces | GET | 获取所有省份 |
| /region/cities/{provinceCode} | GET | 获取省份下城市 |
| /region/districts/{cityCode} | GET | 获取城市下区县 |

### 4.2 返回数据格式
```json
{
  "code": 200,
  "data": [
    { "cde": "110000", "name": "北京市", "prntCde": "0", "lvl": 1 }
  ]
}
```

## 5. 验收标准

- [ ] 省市区使用下拉选择，非文本输入
- [ ] 选择省份后城市下拉自动更新
- [ ] 选择城市后区县下拉自动更新
- [ ] 编辑地址时省市区正确回显
- [ ] 手机号自动格式化显示
- [ ] 地址增删改查功能正常
- [ ] npm run build 构建成功
