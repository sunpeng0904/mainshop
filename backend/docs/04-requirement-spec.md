# 需求规格说明书 (SRS)

## 1. 引言

### 1.1 目的
本文档描述地址管理模块优化的功能需求和非功能需求，为设计和开发提供依据。

### 1.2 范围
本项目范围包括地址管理模块的性能优化、功能增强和用户体验改进。

### 1.3 术语定义
| 术语 | 定义 |
|------|------|
| 地址 | 用户的收货地址信息 |
| 省市区 | 行政区划的三级结构 |
| 默认地址 | 用户设置的首选收货地址 |
| 三级联动 | 省、市、区三级选择联动 |

## 2. 总体描述

### 2.1 产品前景
优化地址管理模块，提升系统性能和用户体验，支持电商业务的快速发展。

### 2.2 用户特征
- **普通用户**：管理个人收货地址，要求操作简便、响应快速
- **管理员**：管理区域数据，要求数据准确、完整

### 2.3 假设与依赖
- 假设：数据库环境正常，Redis服务可用
- 依赖：现有地址管理模块代码、区域数据服务

## 3. 功能需求

### 3.1 地址列表查询优化（REQ-001）

#### 3.1.1 需求描述
优化地址列表查询性能，减少响应时间，提升用户体验。

#### 3.1.2 输入
- 用户ID

#### 3.1.3 处理
1. 添加数据库索引：user_id, is_default, create_time
2. 优化查询语句，减少不必要的字段查询
3. 使用分页查询，避免一次性加载所有数据

#### 3.1.4 输出
- 地址列表（分页）
- 响应时间 < 100ms

### 3.2 地址数据缓存机制（REQ-002）

#### 3.2.1 需求描述
实现地址数据缓存，减少数据库访问，提升响应速度。

#### 3.2.2 输入
- 用户ID
- 地址ID

#### 3.2.3 处理
1. 使用Redis缓存用户地址列表
2. 缓存过期时间：30分钟
3. 地址变更时清除缓存

#### 3.2.4 输出
- 缓存命中时直接返回缓存数据
- 缓存未命中时查询数据库并更新缓存

### 3.3 地址输入验证增强（REQ-003）

#### 3.3.1 需求描述
增强地址输入验证，提高数据质量。

#### 3.3.2 输入
- 地址信息（收货人、手机号、省市区、详细地址）

#### 3.3.3 处理
1. 手机号验证：11位数字，符合运营商规则
2. 邮编验证：6位数字
3. 详细地址验证：长度限制，特殊字符过滤
4. 收货人验证：长度限制，特殊字符过滤

#### 3.3.4 输出
- 验证通过：返回成功
- 验证失败：返回具体错误信息

### 3.4 省市区三级联动数据优化（REQ-004）

#### 3.4.1 需求描述
优化省市区三级联动数据查询，提升用户体验。

#### 3.4.2 输入
- 父级区域编码

#### 3.4.3 处理
1. 缓存区域数据到Redis
2. 提供批量查询接口
3. 支持按编码或名称查询

#### 3.4.4 输出
- 区域列表（编码、名称）

### 3.5 地址搜索功能（REQ-005）

#### 3.5.1 需求描述
支持地址关键词搜索，方便用户快速找到地址。

#### 3.5.2 输入
- 用户ID
- 搜索关键词

#### 3.5.3 处理
1. 在详细地址、收货人、手机号字段中搜索
2. 支持模糊匹配
3. 按匹配度排序

#### 3.5.4 输出
- 匹配的地址列表

## 4. 非功能需求

### 4.1 性能需求
- 地址列表查询响应时间 < 100ms
- 缓存命中率 > 80%
- 支持1000并发用户

### 4.2 安全需求
- 地址数据只能被地址所有者访问
- 敏感信息（手机号）脱敏显示
- 防止SQL注入和XSS攻击

### 4.3 可用性需求
- 界面操作简单直观
- 错误提示清晰明确
- 支持移动端和PC端

## 5. 接口需求

### 5.1 用户接口
- 地址列表页面
- 地址编辑页面
- 地址搜索页面

### 5.2 硬件接口
- 无特殊硬件要求

### 5.3 软件接口
- MySQL数据库
- Redis缓存
- 区域数据服务

## 6. 数据需求

### 6.1 数据模型
```
UserAddress
├── id: Long (主键)
├── userId: Long (用户ID)
├── receiverName: String (收货人)
├── receiverPhone: String (手机号)
├── provinceCode: String (省编码)
├── cityCode: String (市编码)
├── districtCode: String (区编码)
├── detailAddress: String (详细地址)
├── isDefault: Integer (是否默认)
├── createTime: DateTime (创建时间)
├── updateTime: DateTime (更新时间)
└── deleted: Integer (逻辑删除)
```

### 6.2 数据字典
| 字段 | 类型 | 长度 | 必填 | 说明 |
|------|------|------|------|------|
| id | Long | - | 是 | 主键，自增 |
| userId | Long | - | 是 | 用户ID |
| receiverName | String | 50 | 是 | 收货人姓名 |
| receiverPhone | String | 11 | 是 | 手机号 |
| provinceCode | String | 6 | 是 | 省编码 |
| cityCode | String | 6 | 是 | 市编码 |
| districtCode | String | 6 | 是 | 区编码 |
| detailAddress | String | 200 | 是 | 详细地址 |
| isDefault | Integer | - | 是 | 是否默认（0否1是） |
| createTime | DateTime | - | 是 | 创建时间 |
| updateTime | DateTime | - | 是 | 更新时间 |
| deleted | Integer | - | 是 | 逻辑删除（0正常1删除） |
