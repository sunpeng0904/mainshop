# 项目收尾 Skill

## Overview

完成项目收尾工作，确保项目成果交付和知识沉淀，包括验收、总结和归档。

## When to Use

- 项目开发完成，需要进行验收
- 需要总结项目经验教训
- 需要归档项目文档
- 需要释放项目资源和解散团队

## Core Pattern

| 阶段 | 活动 | 输出 |
|------|------|------|
| 交付物验收 | 检查、测试、签收 | 验收报告 |
| 项目总结 | 成果总结、经验教训 | 项目总结 |
| 文档归档 | 整理、归档、更新资产 | 归档清单 |
| 团队解散 | 释放资源、绩效评估 | 资源释放确认 |

## Implementation

### 1. 交付物验收
- 检查交付物完整性
- 验收测试
- 签署验收报告

### 2. 项目总结
- 总结项目成果
- 分析经验教训
- 提出改进建议

### 3. 文档归档
- 整理项目文档
- 归档到知识库
- 更新组织过程资产

### 4. 团队解散
- 释放项目资源
- 团队绩效评估
- 庆祝项目成功

## Templates

### 验收报告模板

```markdown
# 项目验收报告

## 项目信息
- 项目名称：[名称]
- 项目编号：[编号]
- 验收日期：[YYYY-MM-DD]

## 验收内容
| 交付物 | 验收标准 | 验收结果 | 备注 |
|--------|----------|----------|------|
| [交付物] | [标准] | 通过/不通过 | [备注] |

## 验收结论
- [ ] 通过验收
- [ ] 有条件通过（条件：...）
- [ ] 不通过（原因：...）

## 签字确认
- 项目经理：_________ 日期：_________
- 客户代表：_________ 日期：_________
- 质量代表：_________ 日期：_________
```

### 项目总结模板

```markdown
# 项目总结

## 项目概况
- 项目周期：[开始] - [结束]
- 项目团队：[人数]
- 项目成本：[金额]

## 项目成果
- [成果1]
- [成果2]

## 经验教训
### 成功经验
- [经验1]
- [经验2]

### 改进点
- [改进1]
- [改进2]

## 建议
- [建议1]
- [建议2]
```

## Quality Checklist

- [ ] 交付物验收完整
- [ ] 文档归档齐全
- [ ] 经验教训总结到位
- [ ] 资源释放完成

## Quick Reference

| 操作 | 说明 |
|------|------|
| 验收检查 | 对照验收标准逐项检查 |
| 签署报告 | 三方签字确认 |
| 经验总结 | 收集团队反馈，分类整理 |
| 文档归档 | 按模板整理，存入知识库 |
| 资源释放 | 释放人力、环境、许可证 |

## Common Mistakes

- 验收标准不明确，导致验收争议
- 跳过项目总结，错失知识沉淀机会
- 文档归档不完整，后续项目无法复用
- 资源释放不及时，造成成本浪费
- 未正式关闭项目，导致职责不清

## Dependencies

- 项目启动技能（project-init）
- 进度跟踪技能（progress-track）
