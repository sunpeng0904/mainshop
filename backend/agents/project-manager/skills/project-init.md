# 项目启动 Skill

## Overview

完成项目启动，明确项目目标、范围、干系人，生成项目章程。

## When to Use

- 新项目立项，需要生成项目章程
- 需要识别和登记项目干系人
- 需要明确项目目标、范围和约束条件
- 收到项目启动指令或立项审批通过

## Core Pattern

| 阶段 | 输入 | 输出 |
|------|------|------|
| 需求收集 | 项目背景、业务目标 | 干系人列表 |
| 目标定义 | 干系人需求、约束条件 | SMART目标、范围说明 |
| 章程编制 | 目标、范围、干系人 | 项目章程 |

## Implementation

### 1. 需求收集
- 收集项目背景信息
- 明确业务目标
- 识别干系人

### 2. 目标定义
- 定义项目目标（SMART原则）
- 明确项目范围
- 确定约束条件

### 3. 章程编制
- 编制项目章程
- 识别关键里程碑
- 确定审批流程

### 4. 质量检查
- 检查完整性
- 检查规范性
- 生成审核报告

## Quality Checklist

- [ ] 项目目标符合SMART原则
- [ ] 范围边界清晰
- [ ] 干系人识别完整
- [ ] 里程碑合理
- [ ] 风险已识别

## Quick Reference

| 操作 | 说明 |
|------|------|
| 收集背景 | 从业务方获取项目背景和目标 |
| 识别干系人 | 列出所有受影响的角色 |
| SMART目标 | 具体、可衡量、可达成、相关、有时限 |
| 编制章程 | 使用模板填写所有必填项 |
| 审批流转 | 提交发起人审批 |

## Common Mistakes

- 目标模糊，不符合SMART原则
- 遗漏关键干系人，导致后期需求变更
- 范围边界不清，导致范围蔓延
- 约束条件和假设条件未明确记录
- 风险识别不充分，缺少应对措施

## Dependencies

- 需求分析技能（requirement-analysis）
- 风险管理技能（risk-manage）
