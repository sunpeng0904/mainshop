# 风险管理 Skill

## Overview

建立风险管理体系，确保项目风险可控，包括风险识别、评估、应对和监控。

## When to Use

- 项目启动阶段需要识别风险
- 项目执行中出现潜在风险信号
- 需要更新风险登记册
- 风险状态变化需要调整应对措施

## Core Pattern

| 阶段 | 活动 | 输出 |
|------|------|------|
| 风险识别 | 识别技术/资源/进度/范围/外部风险 | 风险清单 |
| 风险评估 | 可能性×影响=风险值 | 风险等级 |
| 风险应对 | 规避/转移/减轻/接受 | 应对计划 |
| 风险监控 | 定期检查、更新登记册 | 状态报告 |

## Implementation

### 1. 风险识别
- 技术风险
- 资源风险
- 进度风险
- 范围风险
- 外部风险

### 2. 风险评估
- 可能性评估（1-5）
- 影响程度评估（1-5）
- 风险值 = 可能性 × 影响

### 3. 风险应对
- 规避：改变计划消除风险
- 转移：将风险转移给第三方
- 减轻：降低风险可能性或影响
- 接受：接受风险存在

### 4. 风险监控
- 定期检查风险状态
- 更新风险登记册
- 触发应急计划

## Templates

### 风险登记册模板

```markdown
# 风险登记册

| 编号 | 风险描述 | 类别 | 可能性 | 影响 | 风险值 | 应对措施 | 责任人 | 状态 |
|------|----------|------|--------|------|--------|----------|--------|------|
| R001 | [描述] | 技术 | 3 | 4 | 12 | [措施] | [姓名] | 监控中 |
| R002 | [描述] | 资源 | 2 | 3 | 6 | [措施] | [姓名] | 已关闭 |

## 风险等级
- 高风险（15-25）：立即处理
- 中风险（8-14）：重点关注
- 低风险（1-7）：定期监控
```

## Quality Checklist

- [ ] 风险识别全面
- [ ] 评估方法合理
- [ ] 应对措施有效
- [ ] 责任人明确
- [ ] 监控机制健全

## Quick Reference

| 操作 | 说明 |
|------|------|
| 风险识别 | 按类别逐项检查 |
| 评估打分 | 可能性(1-5) × 影响(1-5) |
| 风险等级 | 高(15-25) / 中(8-14) / 低(1-7) |
| 应对策略 | 规避/转移/减轻/接受 |
| 状态更新 | 定期检查并更新登记册 |

## Common Mistakes

- 风险识别不全面，遗漏关键风险
- 评估主观随意，缺乏客观标准
- 应对措施不具体，无法执行
- 责任人不明确，无人跟进
- 监控流于形式，未定期更新

## Dependencies

- 项目启动技能（project-init）
- 项目计划技能（project-plan）
