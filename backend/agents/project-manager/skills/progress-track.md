# 进度跟踪 Skill

## Overview

实时监控项目进度，识别偏差，采取纠正措施，确保项目按计划推进。

## When to Use

- 项目执行阶段需要跟踪进度
- 发现进度偏差需要分析原因
- 需要生成进度报告
- 需要调整计划或资源分配

## Core Pattern

| 阶段 | 活动 | 输出 |
|------|------|------|
| 进度收集 | 收集实际进度数据 | 进度数据 |
| 偏差分析 | 计划vs实际对比 | 偏差报告 |
| 纠正措施 | 制定并执行纠正措施 | 行动计划 |
| 报告生成 | 汇总分析结果 | 进度报告 |

## Implementation

### 1. 进度收集
- 收集各任务实际进度
- 更新进度数据
- 记录完成情况

### 2. 偏差分析
- 计划 vs 实际对比
- 识别进度偏差
- 分析偏差原因

### 3. 纠正措施
- 制定纠正措施
- 调整资源分配
- 更新进度计划

### 4. 报告生成
- 生成进度报告
- 识别风险和问题
- 提出改进建议

## Templates

### 进度报告模板

```markdown
# 进度报告

## 报告信息
- 报告日期：[YYYY-MM-DD]
- 报告周期：[起始日期] - [结束日期]
- 项目经理：[姓名]

## 总体进度
- 计划进度：XX%
- 实际进度：XX%
- 进度偏差：XX%

## 里程碑状态
| 里程碑 | 计划日期 | 实际日期 | 状态 |
|--------|----------|----------|------|
| [名称] | [日期] | [日期] | 完成/延期/进行中 |

## 任务完成情况
| 任务 | 负责人 | 计划完成 | 实际完成 | 状态 |
|------|--------|----------|----------|------|
| [任务] | [姓名] | [日期] | [日期] | 完成/延期 |

## 问题与风险
| 编号 | 描述 | 影响 | 措施 |
|------|------|------|------|
| [编号] | [描述] | [影响] | [措施] |

## 下阶段计划
- [计划1]
- [计划2]
```

## Quality Checklist

- [ ] 进度数据准确
- [ ] 偏差分析合理
- [ ] 纠正措施可行
- [ ] 报告及时完整

## Quick Reference

| 操作 | 说明 |
|------|------|
| 收集进度 | 从各负责人获取实际完成情况 |
| 偏差计算 | 实际进度 - 计划进度 |
| 原因分析 | 人员/技术/需求/外部因素 |
| 纠正措施 | 赶工/快速跟进/范围调整 |
| 报告频率 | 周报/双周报/月报 |

## Common Mistakes

- 进度数据收集不及时，报告滞后
- 偏差分析停留在表面，未找根本原因
- 纠正措施不可行，缺乏资源支持
- 报告内容空洞，缺乏 actionable 信息
- 只关注进度，忽视质量和风险

## Dependencies

- 项目计划技能（project-plan）
- 风险管理技能（risk-manage）
