| @tdDesign | 单行/多行注释 | 标识注释是否是业务逻辑设计的注释 | 在需要被标识的单行/多行注释前面加上@tdDesign |
| @tdDeep | 单行/多行注释 | 标识业务逻辑设计的注释是否需要提取调用方法/代码块中的业务逻辑注释 | 在进行调用方法代码行或者代码块上加上// @tdDeep , 即可深入解析业务逻辑注释                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| @tdItem | 单行/多行注释 | 可以对代码块的逻辑进行整体说明 | 在代码块内部的第一行注释上加@tdItem <br/>示例：if (a == 0) {<br/>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;// @tdItem a等于0<br/>} |
| @tdApiDesc | 方法注释 | 可以对接口的功能进行描述 | 在对应接口的方法注释中，添加@tdApiDesc 并填写接口功能描述（注：如果涉及多行每行注释前都需要加@tdApiDesc ） |
| @tdAuthDesc | 方法注释 | 可以对接口权限信息进行描述 | 在对应接口的方法注释中，添加@tdAuthDesc 并填写接口权限信息（注：如果涉及多行每行注释前都需要加@tdAuthDesc ） |
| @tdNoteItem | 方法注释 | 可以添加接口注意事项信息 | 在对应接口的方法注释中，添加@tdNoteItem 并填写注意事项（注：如果涉及多行每行注释前都需要加@tdNoteItem ） |
| @TdRelationTables | 注解 | 可以添加涉及表信息及示例SQL | 在对应接口的方法上添加对应注解，dbInstName: 数据库模式名称（优先获取tables中信息）、schema: 优先获取tables中信息、tables: 表信息（name: 表名（优先级高于mybatis对应的实体Class）、code: 表编码（优先级高于mybatis对应的实体Class）、dbInstName: 数据库模式名称（优先级高于mybatis对应的实体Class）、schema: 优先级高于mybatis对应的实体Class、clazz: mybatis对应的实体Class（表名取注释的描述））、example：SQL示例<br/>示例：@TdRelationTables(dbInstanceName = "lems", schema = "lems", tables={<br/>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;@TdTableInfo(name = "会商会表", entity = CstaMeetCstlDO.class)<br/>}) |
| @TdTableInfo | 注解 | 可以添加涉及表信息及示例SQL | 在@TdRelationTables中的tables中使用，name: 表名（优先级高于mybatis对应的实体Class）、code: 表编码（优先级高于mybatis对应的实体Class）、dbInstName: 数据库模式名称（优先级高于mybatis对应的实体Class）、schema: 优先级高于mybatis对应的实体Class、clazz: mybatis对应的实体Class（表名取注释的描述） |
| @Api | swagger注解 | 描述功能模块信息 | 在controller类上使用，tags: 模块标识名称 |
| @ApiOperation | swagger注解 | 描述接口信息 | 在controller 方法上使用，value: 接口名称（单属性时，可以不填） |
| @ApiModel | swagger注解 | 描述数据对象信息 | 在数据对象类上使用，value: 数据对象名称（单属性时，可以不填） |
| @ApiModelProperty | swagger注解 | 描述数据对象属性信息 | 在数据对象属性上使用，value: 属性描述名称、name: 属性标识名称（可以不填，默认取数据对象属性名）、notes: 属性备注 |

### 3、使用流程

[1] 设计人员创建设计分支，并拉取设计代码到本地

[2] 设计人员使用代码生成工具生成基础代码

[3] 设计人员在基础代码的基础上进行代码逻辑设计

[4] 设计人员提交设计代码并生成设计文档

[5] 开发人员基于设计分支创建开发分支

[6] 开发人员拉取开发分支代码到本地进行功能开发

package org.neris.lems.lemsapigenerate.demo.web;

import io.swagger.annotations.Api;
import io.swagger.annotations.ApiOperation;
import lombok.RequiredArgsConstructor;

import model.web.org.neris.tech.techdesign.demo.Result;
import request.model.web.org.neris.tech.techdesign.demo.CstaMeetCstlSUPInfo;
import anon.common.org.neris.tech.techdesign.sdk.RelationTables;
import anon.common.org.neris.tech.techdesign.sdk.TableInfo;
import org.springframework.validation.annotation.Validated;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import javax.validation.Valid;
import javax.validation.constraints.NotNull;

/**
 * 会商会请示信息接口信息
 *
 * @author jan.di
 * @date 2024/12/17
 */
@Api(tags = "会商会接口信息")
@Validated
@RestController
@RequiredArgsConstructor
@RequestMapping(path = "/api/v1/cstaMeetCslt")
public class CstaMeetCsltController {

    private final CstaMeetCstlService cstaMeetCstlService;

    /**
     * 会商会保存/修改流程信息接口
     * @tdApiDesc 用于保存/修改会商会数据，并对接流程
     * @tdAuthDesc 有稽查系统访问权限用户均可访问
     * @tdNoteItem 会议号自动生成逻辑
     * @tdNoteItem 流程对接逻辑
     * @param cstaMeetCstlSUPInfo 会商会保存/修改&流程信息
     * @param <T> 泛型
     * @return Result<T>
     */
    @RelationTables(dbInstName = "lems", tables = {
            @TableInfo(name = "会商会请示表", entity = CstaMeetCstlDO.class),
            @TableInfo(name = "会商会操作信息表", entity = CstaMeetCsltOprtInfoDO.class),
            @TableInfo(name = "编码生成管理表", entity = LemsInfoCdeDo.class),
            @TableInfo(name = "业务附件信息表", entity = BizAttachmentDO.class)
    }, notes = "主要涉及相关表的新增/修改操作", example = "select * from csta_meet_cstl where csta_meet_cslt_id = {cstaMeetCsltId}")
    @ApiOperation(value = "会商会保存/修改流程信息接口", response = Result.class)
    @PostMapping(path = "/saveOrUpdateCstaMeetCsltApprovalInfo")
    public <T> Result<T> saveOrUpdateCstaMeetCsltApprovalInfo(@RequestBody @Valid @NotNull CstaMeetCstlSUPInfo cstaMeetCstlSUPInfo) {
        // @tdDesign 参数转换
        CstaMeetCstlSUPInfoDTO cstaMeetCsltSUPDTO = null;

        // @tdDeep 保存/修改，并对接流程
        cstaMeetCstlService.saveOrUpdateCstaMeetCsltApprovalInfo(cstaMeetCsltSUPDTO);

        // @tdDesign 返回结果
        return Result.success();
    }
}
