kingbase数据库分页查询注意事项
问题描述：分页查询时第一页有的内容在第二页也出现了。

原因分析：分页查询时加了order by 条件，有的数据按照ordey by排序数据库无法确认真实顺序。oracle和mysql因在开发人员加上order by 条件的基础上还有默认的唯一排序规则所以不会出现此问题。

解决： 在 `order by` 条件后 加上主键排序。
ORDER BY  "s_time" ASC NULLS LAST, "id" ASC

经排查：新仿真nginx的 /etc/sysctl.conf 中的
net.ipv4.tcp_tw_recycle=1
此配置表示开启TCP连接中TIME-WAIT sockets的快速回收，默认为0，表示关闭。
解释：当多个客户端通过nat（网络地址转换）方式联网，并与服务端交互时，服务端看到的是同一个ip，由于客户端的时间戳可能存在差异，于是从服务端来看会出现时间戳错乱的情况导致时间戳小的数据包被丢失。
解决：net.ipv4.tcp_tw_recycle=0

## 4.47 数据库时间戳查询失效
问题描述：数据库中默认创建的时间戳是TIMESTAMP WITHOUT TIME ZONE，此类型没有精度，实际存储有毫秒值，代码查询时对象用的TIMESTAMP字段，进行了格式化展示的是年月日时分秒 @JsonFormat(timezone = "Asia/Shanghai", pattern = "yyyy-MM-dd HH:mm:ss")此时用此字段进行数据库查询会匹配不上。
解决：
方案一：去掉 @JsonFormat(timezone = "Asia/Shanghai", pattern = "yyyy-MM-dd HH:mm:ss")注解，技术字段不做任何格式处理。
方案二：将数据库时间戳类型设置精度TIMESTAMP(0) without time zone。 这样数据库存储和前端接收内容一致，就是年与日时分秒了。

 详细要求如下： 
1、新系统第一位版本号从1开始，如系统发生架构变更，系统重构，第一位版本号加1，如V1.0.0.0->V2.0.0.0

5、每次提交生产部署后，第四位要清零，再次部署时，需要遵循1,2,3原则制定版本号。

上传生产环境的DDL、DML
1. SQL编写规范
l 脚本命名包括时间、项目英文名，以及脚本要解决问题的简单描述，最后要有DML或DDL字样+执行序号，脚本整体命名格式和示例如下：
格式：yyyyMMdd_lems_XXX_ddl_01.sql
示例：20211130_lems_统计口径需求上线_ddl_01.sql
格式：yyyyMMdd_pfrs_XXX__dml_02.sql
示例：20211115_pfrs_监管协作一期__dml_02.sql
l 执行脚本需要有前备和回退机制，要求如下：
insert类型无需前备脚本，只需提回滚（delete）脚本和执行脚本。
update类型既需要前备脚本（insert），也需要执行脚本和回滚脚本（delete）脚本。
delete类型无需回滚脚本，只需提前备（insert）脚本和执行脚本。
前备和回退脚本的命名参照执行脚本的命名，追加backup（备份）和rollback（回退）字样：
格式：yyyyMMdd_lems_XXX_ddl_01_rollback.sql
示例：20211130_lems_统计口径需求上线_ddl_01_rollback.sql
格式：yyyyMMdd_pfrs_xxx__dml_02_backup.sql
示例：20211115_pfrs_监管协作一期__dml_02_backup.sql
l SQL脚本书写时，DDL脚本和DML脚本必须分开编写，前备脚本和回滚脚本也要单独编写，严禁和执行脚本写在同一个文本中。
l SQL脚本后缀统一为.sql，避免使用txt等文件类型。

Linux实用命令

1. 获取CPU型号信息
在命令行中输入“ cat /proc/cpuinfo | grep name | cut -f2 -d: |uniq -c”可以查询CPU的型号。结果为“4 Intel(R) Xeon(R) CPU E7-4850 v3 @ 2.20GHz”。
2.获取CPU的个数（几核CPU）
在命令行中输入“grep 'physical id' /proc/cpuinfo | sort | uniq | wc -l”可以查询CPU的物理个数。结果为2，说明CPU有两个。在命令行中输入“cat /proc/cpuinfo |grep "cores"|uniq”可以查看CPU的核数。结果为2，说明一个CPU的有2个芯片组，总核数是4核。
扩展阅读：
2.1.物理cpu数：主板上实际插入的cpu数量，可以数不重复的 physical id 有几个（physical id）
2.2.cpu核数：单块CPU上面能处理数据的芯片组的数量，如双核、四核等 （cpu cores）
3.查看系统内存
在命令行中输入“  cat /proc/meminfo | grep MemTotal ”可以查看内存的大小。
4.查看操作系统版本
在命令行中输入“cat /proc/version”可以获得操作系统的版本信息，但是在实际填写的时候，我们一般不采用这个信息，而是获取发行版本信息。（这条语句有用不常用）
常规情况下，在命令中输入“cat /etc/centos-release”或者是“cat /etc/issue”得到的信息才是文档中要填的。得到的结果为“CentOS Linux release 7.5.1804 (Core)”。一般文档中填的都是Linux CentOS7.5这个结果。
5.查看硬盘大小
在命令行中输入“ fdisk -l |grep Disk ”可以得到硬盘的容量信息。
结果为：Disk /dev/sda: 42.9 GB, 42949672960 bytes, 83886080 sectors说明服务器的总容量约为42.9G。

7.查看文件大小

UOS系统安装防火墙
 
1、将以上文件传入到服务器中；
2、通过命令 sudo dpkg -i ufw_0.36-1_all.deb  解压安装；
3、只给本机器添加白名单
sudo ufw allow from ip   #允许此ip访问所有的本机端口
对外开通需要访问的端口
sudo ufw allow port  # 允许外部访问端口，多个端口分开执行；
如果端口放开有误，可以禁止外部端口访问
sudo ufw delete allow port  # 禁止外部访问port端口
开启防火墙
sudo ufw enable
查看防火墙状态
sudo ufw status # 如果状态显示 inactive,则证明防火墙未启动.
如需关闭防火墙
sudo ufw disable
