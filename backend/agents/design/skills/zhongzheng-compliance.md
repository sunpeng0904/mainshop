# 中证贯标

## Overview

确保所有设计活动符合中证体系规范。通过标准解读、差距分析、整改计划、合规验证四个步骤实现合规。

## When to Use

- 需要确保设计符合中证体系要求
- 需要进行合规检查
- 需要生成合规报告
- 需要进行差距分析和整改计划

## Core Pattern

| 合规步骤 | 说明 | 输出 |
|----------|------|------|
| 标准解读 | 解读中证标准要求 | 适用条款清单 |
| 差距分析 | 对比现有设计 | 差距分析报告 |
| 整改计划 | 制定整改措施 | 整改计划 |
| 合规验证 | 验证整改效果 | 合规报告 |

## Implementation

1. **标准解读** - 解读中证标准要求、识别适用条款、确定合规等级
2. **差距分析** - 对比现有设计、识别差距、评估风险
3. **整改计划** - 制定整改措施、确定优先级、分配责任
4. **合规验证** - 验证整改效果、生成合规报告、持续监控

## Quality Checklist

- [ ] 检查项覆盖全面
- [ ] 差距分析准确
- [ ] 整改计划可行
- [ ] 合规报告完整

## Common Mistakes

- 检查项遗漏，覆盖不全面
- 差距分析不准确，整改措施针对性差
- 整改计划不可行，资源分配不合理
- 合规报告不完整，缺少关键信息
- 忽视持续监控，合规状态无法维持

## Quick Reference

| 合规维度 | 检查要点 |
|----------|----------|
| 文档规范 | 结构、术语、版本、审批 |
| 命名规范 | 词根字典、编码规范 |
| 架构规范 | 分层、接口、数据模型 |
| 开发规范 | 代码、注释、异常、日志 |
| 测试规范 | 计划、用例、报告、缺陷 |
| 部署规范 | 方案、环境、回滚、监控 |

| 合规状态 | 说明 |
|----------|------|
| 合规 | 满足所有要求 |
| 基本合规 | 需整改后满足 |
| 不合规 | 需重新设计 |
