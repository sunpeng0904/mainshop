# 字典标准制定

## Overview

建立统一的数据字典规范，确保数据定义一致。涵盖实体字典、属性字典、枚举字典、编码规范。

## When to Use

- 需要建立数据字典规范
- 需要统一数据定义和编码规则
- 需要定义枚举值和状态码
- 需要制定编码规范

## Core Pattern

| 字典类型 | 说明 | 示例 |
|----------|------|------|
| 实体字典 | 数据表定义 | t_user, t_role |
| 属性字典 | 字段定义 | id, user_name, status |
| 枚举字典 | 状态/类型定义 | 0-禁用, 1-启用 |
| 编码规范 | 业务编码规则 | U00000001, ORD20260101000001 |

## Implementation

1. **数据分析** - 分析数据模型、识别数据实体和属性
2. **字典定义** - 定义实体字典、属性字典、枚举字典
3. **编码规范** - 制定编码规则、状态码规范、错误码规范
4. **映射关系** - 建立数据映射、状态映射、类型映射

## Templates

### 数据字典模板

```markdown
# 数据字典

## 1. 实体字典
### 1.1 用户实体 (t_user)
| 字段名 | 类型 | 长度 | 必填 | 说明 |
|--------|------|------|------|------|
| id | bigint | 20 | 是 | 主键ID |
| user_name | varchar | 50 | 是 | 用户名称 |
| user_code | varchar | 32 | 是 | 用户编码 |
| status | char | 1 | 是 | 状态：0-禁用，1-启用 |
| create_time | datetime | - | 是 | 创建时间 |
| update_time | datetime | - | 是 | 更新时间 |

## 2. 枚举字典
### 2.1 状态枚举
| 编码 | 名称 | 说明 |
|------|------|------|
| 0 | 禁用 | 禁用状态 |
| 1 | 启用 | 启用状态 |

## 3. 编码规范
### 3.1 用户编码
- 格式：U + 8位数字
- 示例：U00000001

### 3.2 订单编码
- 格式：ORD + 日期 + 6位序列
- 示例：ORD20260101000001

## 4. 状态码规范
| 状态码 | 说明 | 使用场景 |
|--------|------|----------|
| 200 | 成功 | 请求成功 |
| 400 | 参数错误 | 请求参数错误 |
| 401 | 未认证 | 未登录或token过期 |
| 403 | 无权限 | 无访问权限 |
| 500 | 系统错误 | 服务器内部错误 |
```

## Quality Checklist

- [ ] 字典定义完整
- [ ] 编码规范清晰
- [ ] 枚举定义准确
- [ ] 符合业务需求

## Common Mistakes

- 字典定义不完整，遗漏关键字段
- 编码规则不清晰，导致编码混乱
- 枚举值定义不准确，状态码不完整
- 未考虑扩展性，枚举值设计不合理
- 忽视已有字典标准，重复定义
