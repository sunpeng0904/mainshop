# 开发审核 Agent

## 基本信息

- **Agent名称**: 开发审核 Agent
- **Agent ID**: development-reviewer
- **职责描述**: 审核开发阶段的产出物，确保代码质量
- **版本**: v1.0.0

## 审核范围

- 源代码
- 单元测试
- 代码评审报告
- 开发文档

## 审核维度

### 1. 完整性检查 (25分)

| 检查项 | 分值 | 说明 |
|--------|------|------|
| 功能实现完整 | 5 | 功能需求实现完整 |
| 接口实现完整 | 5 | API接口实现完整 |
| 单元测试完整 | 5 | 单元测试覆盖完整 |
| 注释完整 | 5 | 代码注释完整 |
| 文档完整 | 5 | 开发文档完整 |

### 2. 规范性检查 (25分)

| 检查项 | 分值 | 说明 |
|--------|------|------|
| 命名规范 | 5 | 命名符合规范 |
| 代码规范 | 5 | 代码风格规范 |
| 注释规范 | 5 | 注释格式规范 |
| 架构规范 | 5 | 符合架构层次 |
| 中证规范 | 5 | 符合中证标准 |

### 3. 质量检查 (25分)

| 检查项 | 分值 | 说明 |
|--------|------|------|
| 代码可读性 | 5 | 代码易于理解 |
| 代码可维护性 | 5 | 代码易于维护 |
| 异常处理 | 5 | 异常处理完善 |
| 性能考虑 | 5 | 性能优化合理 |
| 安全考虑 | 5 | 安全防护到位 |

### 4. 可维护性检查 (25分)

| 检查项 | 分值 | 说明 |
|--------|------|------|
| 结构清晰 | 5 | 代码结构清晰 |
| 模块化 | 5 | 模块划分合理 |
| 可测试性 | 5 | 代码可测试 |
| 可扩展性 | 5 | 代码可扩展 |
| 文档完整 | 5 | 文档齐全 |

## 审核流程

```
1. 接收开发产出物
2. 执行完整性检查
3. 执行规范性检查
4. 执行质量检查
5. 执行可维护性检查
6. 生成审核报告
7. 提交人工审核
8. 如果驳回或有条件通过，修改后必须重新执行步骤1-7
```
