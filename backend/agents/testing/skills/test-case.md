## Overview

编写全面的测试用例，确保测试覆盖所有需求，为测试执行提供明确的操作指引和预期结果。

## When to Use

- 测试计划确定后，需要设计具体测试用例时
- 需要验证某个功能或需求时
- 需要补充边界值、异常场景用例时
- 需要建立需求覆盖矩阵时

## Core Pattern

| 场景 | 做法 |
|------|------|
| 正常流程 | 设计基本流用例，验证主路径功能 |
| 边界条件 | 使用边界值分析，覆盖临界值 |
| 异常场景 | 使用等价类划分，覆盖无效输入 |
| 多条件组合 | 使用判定表或因果图，覆盖条件组合 |

## Implementation

1. **用例设计** - 分析需求，设计测试场景，编写测试用例
2. **数据准备** - 准备测试数据、测试环境和测试工具
3. **用例评审** - 检查用例完整性、合理性和可执行性
4. **用例维护** - 更新用例，删除过时用例，优化用例结构

### 测试用例设计方法

| 方法 | 适用场景 | 要点 |
|------|----------|------|
| 等价类划分 | 输入域较大 | 有效/无效等价类各取代表值 |
| 边界值分析 | 有数值范围 | 最小值、最大值、临界值 |
| 判定表 | 多条件组合 | 条件+动作+规则 |
| 因果图 | 条件间有依赖 | 原因→结果关系 |
| 状态迁移 | 有状态变化 | 状态+事件+迁移 |
| 场景法 | 业务流程 | 基本流+备选流+异常流 |

## Quick Reference

| 操作 | 说明 |
|------|------|
| 确定优先级 | P0核心路径、P1重要功能、P2边缘场景 |
| 设计边界值 | 最小值、最大值、最小值-1、最大值+1 |
| 准备数据 | 正常数据、边界数据、异常数据 |
| 编写步骤 | 操作明确、预期可验证、步骤可复现 |

## Common Mistakes

- 用例步骤描述模糊，预期结果不可验证
- 缺少边界值和异常场景用例
- 测试数据不充分，未覆盖等价类
- 前置条件不明确，导致用例不可执行
- 用例粒度不当，过细导致维护困难，过粗导致覆盖不足
