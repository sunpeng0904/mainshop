# Playwright API 自动化测试

## 目录结构

```
tests/
├── address.spec.js      # 地址管理模块测试用例
├── test-helpers.js      # 测试辅助工具
└── README.md            # 本文档
```

## 前置条件

1. 应用服务已启动（http://localhost:8080）
2. 数据库已初始化
3. Redis 服务已启动

## 运行测试

### 运行所有测试

```bash
npm test
```

### 运行地址管理模块测试

```bash
npm run test:address
```

### 调试模式运行

```bash
npm run test:debug
```

### 查看测试报告

```bash
npm run test:report
```

## 测试用例说明

### 1. 添加地址 (TC001-TC005)
- 添加非默认地址
- 添加默认地址
- 手机号格式验证
- 必填字段验证

### 2. 获取地址列表 (TC006-TC007)
- 获取列表成功
- 验证新添加的地址

### 3. 获取地址详情 (TC008-TC009)
- 获取存在的地址
- 获取不存在的地址

### 4. 更新地址 (TC010-TC011)
- 更新地址成功
- 更新不存在的地址

### 5. 设置默认地址 (TC012-TC014)
- 设置默认地址成功
- 验证默认地址更新
- 设置不存在的地址

### 6. 获取默认地址 (TC015)
- 获取默认地址成功

### 7. 删除地址 (TC016-TC017)
- 删除地址成功
- 删除不存在的地址

### 8. 性能测试 (TC018-TC019)
- 接口响应时间 < 100ms
- 缓存命中响应时间 < 50ms

### 9. 缓存测试 (TC020)
- 缓存清除验证

## 测试数据

测试使用动态生成的随机数据，包括：
- 随机手机号
- 随机用户名称
- 随机地址详情

## 注意事项

1. 测试会在执行后自动清理创建的测试数据
2. 确保测试环境的数据库可以正常写入
3. 如果测试失败，检查应用日志获取详细错误信息

## CI/CD 集成

在 CI/CD 流水线中运行测试：

```yaml
# GitHub Actions 示例
- name: Run API Tests
  run: |
    npm install
    npm test
```
